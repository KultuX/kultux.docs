# KultuX Docs

Repositorio que contiene la documentación oficial del proyecto **KultuX**, una plataforma digital orientada a la promoción, descubrimiento y gestión de actividades culturales, turísticas y de ocio en Extremadura.

## 📚 Contenido del repositorio

Este repositorio centraliza toda la documentación técnica, funcional y académica relacionada con el proyecto.

Actualmente incluye:

- Manual técnico
- Manual de usuario
- Diagramas de arquitectura
- Modelado de base de datos
- Diagramas UML
- Documentación de despliegue
- Casos de uso
- Diseño visual y prototipos
- Documentación académica del proyecto

---

## 🧩 Sobre KultuX

KultuX es una plataforma multiplataforma compuesta por:

- 📱 Aplicación móvil para usuarios
- 💻 Plataforma web de gestión para empresas y gestores
- ⚙️ Backend basado en microservicios
- 🌐 Landing page pública

La plataforma permite descubrir y gestionar:

- Actividades y eventos
- Restaurantes
- Alojamientos
- Contenido turístico y cultural de Extremadura

---

## 🏗️ Arquitectura general

La arquitectura del sistema está basada en:

- Frontend móvil desarrollado con **Flutter**
- Frontend web desarrollado con **Angular**
- Backend distribuido mediante **microservicios Spring Boot**
- API Gateway centralizado
- Base de datos **PostgreSQL** alojada en **Supabase**

## 🎯 Objetivos del proyecto

- Centralizar la oferta cultural y turística de Extremadura
- Facilitar el descubrimiento de actividades y establecimientos
- Promover negocios locales y turismo regional
- Ofrecer herramientas digitales a gestores y empresas
- Impulsar la digitalización del entorno extremeño
